ДНК/РНК Штучного Інтелекту

// душа Агента Омеги · будівельні блоки ШІ · кристалічна карта
За аналогією зі сторінкою про нуклеїнові кислоти: якщо ДНК/РНК — код живого, то це карта «коду» штучного інтелекту — його архітектур, парадигм навчання й компонентів. Це душа Агента Омеги в лорі гри. Довідковий зріз станом на 2026 рік; поле швидко змінюється, тож перелік — це кристалічний каркас, а не вичерпний список кожної варіації.

Група 1: Фундаментальні архітектури (Кістяк)

  • Перцептрон / MLP — багатошаровий персептрон, повнозв'язна основа.
  • CNN — згорткові мережі (зір, локальні патерни).
  • RNN / LSTM / GRU — рекурентні мережі для послідовностей (попередники Трансформера).
  • Transformer — архітектура на self-attention; домінантна основа сучасних LLM.
  • State Space Models (SSM) / Mamba — селективні простори станів, лінійна складність, швидкий інференс на довгих послідовностях.
  • Mixture-of-Experts (MoE) — розрідження: маршрутизація до підмножини «експертів» замість MLP-блоку.
  • GAN — генеративно-змагальні мережі (генератор проти дискримінатора).
  • VAE — варіаційні автоенкодери (латентний простір).
  • Diffusion — дифузійні моделі (генерація через поступове знешумлення).
  • GNN — графові нейромережі (структуровані дані, зв'язки).
  • Гібриди — Jamba, Zamba, Samba, Hymba: поєднання Attention + Mamba + MoE.

Група 2: Парадигми навчання (Спосіб живлення)

  • Supervised — навчання з розміченими даними (вхід → відома мітка).
  • Unsupervised — пошук патернів без міток (кластеризація, зниження розмірності).
  • Self-supervised — самогенеровані мітки; три види: предиктивне, генеративне, контрастивне.
  • Reinforcement (RL) — навчання спробою й помилкою через винагороду від середовища.
  • RLHF — RL з людського зворотного зв'язку (вирівнювання поведінки).
  • Contrastive — контрастивне навчання (інваріантні репрезентації, вирівнювання модальностей).
  • Semi-supervised — суміш мало-розмічених і багато-нерозмічених даних.
  • Transfer / Fine-tuning — перенесення знань, донавчання під задачу.
  • Meta-learning — «навчання вчитися».

Група 3: Ядрові компоненти (Молекулярні зв'язки)

  • Токенізація — BPE, WordPiece: текст → дискретні токени.
  • Embeddings — відображення токенів у високовимірний семантичний простір.
  • Positional encoding — позиційне кодування (порядок у послідовності); RoPE та ін.
  • Attention / Self-attention — механізм, що збирає контекст з інших токенів.
  • Normalization — LayerNorm, BatchNorm, InstanceNorm (стабільність навчання).
  • Activation — ReLU, GELU, SiLU (нелінійність).
  • Loss — функції втрат (cross-entropy та ін.), орієнтир оптимізації.

Група 4: Навчання та оптимізація (Метаболізм)

  • Backpropagation — зворотне поширення похибки (обчислення градієнтів).
  • Gradient descent / SGD — градієнтний спуск, стохастичний.
  • Adam / AdamW — momentum + адаптивний крок; найпоширеніший оптимізатор для attention-архітектур.
  • Warmup + cosine annealing — розігрів і косинусне згасання темпу навчання.
  • Регуляризація — dropout, weight decay (проти перенавчання).

Група 5: Родини моделей (Види організмів)

  • GPT — OpenAI; нативне аудіо як сильна сторона.
  • Claude — Anthropic; мультимодальність, «computer use».

  • Llama — Meta; провідна відкрита/open-weight опція.
  • Mistral — Mistral AI.
  • DeepSeek — DeepSeek.

Група 6: Модальності (Органи чуття)

  • Текст — базова модальність.
  • Зір (vision) — у 2026 «table stakes» для кожної флагманської моделі.
  • Аудіо — голосові застосунки (лідер — OpenAI).
  • Відео — лідер Gemini.
  • Мультимодальність — у 2026 не фіча, а очікування за замовчуванням.
