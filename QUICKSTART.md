# Quickstart — Use OMEGA in 5 Minutes

## Option 1: Claude

1. Open claude.ai
2. Start new conversation
3. Paste the contents of `AGENT_OMEGA_v1.0.md` as your first message
4. Add: "This is your operating system. Confirm you understand each block."
5. Start working

## Option 2: ChatGPT

1. Open chatgpt.com → GPTs → Create
2. Paste `AGENT_OMEGA_v1.0.md` into System Instructions
3. Save as "OMEGA"
4. Use for any complex thinking task

## Option 3: Any Local LLM (Ollama, LM Studio)

1. Create a modelfile or system prompt file
2. Paste `AGENT_OMEGA_v1.0.md` as system prompt
3. Run with llama3, mistral, or any capable model

## Option 4: VS Code + Continue/Cursor

1. Open `.continue/config.json` or cursor rules
2. Add `AGENT_OMEGA_v1.0.md` content as system prompt
3. Every coding session now runs through OMEGA architecture

## First Test

After setup, send this:

```
I have a complex problem: [describe your problem]
Apply the full OMEGA protocol:
- ARM: find the root
- Design: map dependencies  
- Factory: find 3 micro-cracks
- Absolute Protocol: verify before output
```

Compare the response to what you'd normally get.

- Responses that challenge your framing, not confirm it
- Dependency maps instead of step lists
- Micro-cracks identified before you hit them
