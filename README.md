# Agent Omega: Log Scanner (Chokidar Bridge)

Локальний сканер подій у режимі реального часу для забезпечення неперервного потоку даних у конвеєрі `agent-omega/01_CORE_STATE/`.

## Швидкий старт

1. Ініціалізуйте (якщо ще не):
   ```bash
   npm init -y
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть у режимі перевірки (dry-run):
   ```bash
   npm run dry-run
   ```
4. Запустіть в активному режимі моніторингу:
   ```bash
   npm start
   ```

## Конфігурація
Редагуйте `log_scanner_config.json` щоб вказати `log_dir`, `output_dir`, `mask_keys`, `read_existing` та `dry_run`.

## Примітки з безпеки
- Перший запуск — завжди у dry‑run на тестовій копії даних.
- Переконайтеся, що backups та output доступні лише уповноваженим користувачам.
- Маскуйте PII/секрети перед передачею або спільним використанням логів.
